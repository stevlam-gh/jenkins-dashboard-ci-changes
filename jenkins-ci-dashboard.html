S3 compiler cacheLogs show cache-hit rates, not object bytes, request counts, or transfer bytes. Local Jenkins log size is not cache size.Keep at $0 pending S3 Storage Lens/Cost and Usage data; do not infer it from console text.
ArtifactoryPackage downloads are visible, but console text has no reliable byte/request totals.Keep direct traffic cost at $0 pending Artifactory usage/export; compare only if measured bytes exceed the AWS transfer allowance.
Sonar/controller capacityJenkins identifies Sonar runs, but not Sonar Compute Engine CPU, task duration, or controller resource consumption.Do not allocate shared capacity dollars from Jenkins duration alone; import Sonar task metrics or mark as shared/unpriced.
Retries / failuresTiming events classify TIMEOUT, TEST, ABORTED, UNKNOWN, and SONAR, but retry wrappers and repeated platform events are not a clean per-PR retry ledger.Count attempts from build numbers/status and use failure category as a sensitivity input, not as a causal savings claim.
Recommended avoided-rerun estimate: use a range, not a fabricated point estimate. For comparable non-Sonar runs, calculate max(0, baseline rerun rate − experiment rerun rate) × PR volume. Report 0 / 1 / 2 avoided reruns per 100 PRs as sensitivity cases until the same PRs are retried under both configurations. Then value each avoided rerun using the measured baseline cost and controllable developer minutes.
Cost formulas: EC2 = runtime hours × hourly rate; Mac = max(host-active hours, 24) × effective host rate; EBS = provisioned GB × lifetime months × GB-month rate; cost / successful PR = total cost including failed attempts / successes; cost / controllable minute saved = incremental cost / (baseline compile-link minutes − experiment compile-link minutes).
